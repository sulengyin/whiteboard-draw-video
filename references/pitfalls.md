# 踩坑清单（22 条，按出现频率排序）

每条都是真实返工，不是理论风险。写代码前先扫一遍，能省掉大部分来回。

## 画面 / 笔迹

**1. 六幕全是纯色，什么都看不到**
入场遮罩在 `t=0` 时半径算成 0，整幅图 alpha 归零，只剩纸色。
→ 任何入场动画都要有静帧兜底：`t=0`、暂停、切幕时直接给完整画面。编辑器里最常看的就是 0 秒。

**2. 图片下沿被裁掉**
运镜用 `z=1.07` 并从源图取子矩形，放大量超过了留边。
→ 改成整图缩到 96%，再叠加 ≤3.5% 呼吸；用 9 参数 `drawImage` 画到目标矩形，不从源图裁。

**3. 没画到的地方先露出一整张图的方框**
纸底没抠，画布上是一张不透明的图。
→ 按与纸色的色差算 alpha，把纸底变透明；再与笔刷掩膜 `destination-in` 相乘。

**4. 笔在色块里乱窜**
用 Zhang-Suen 骨架，色块内部纹理让中轴变成一张网。
→ 不要骨架。改为追踪连通域的外轮廓环。

**5. 整幅图像等高线地图**
逐层等距内缩（onion peel）。
→ 不要内缩。只取最外一圈。

**6. 画面一块块空白**
骨架 + 大笔刷，覆盖有洞，中段露出没画的地方。
→ 不要靠笔刷"涂满"。描完轮廓直接 `Path2D` 填充。

**7. 笔在已经画好的内容上来回晃**
最近邻兜底在连通域里乱走，重复描已有线，图在 30% 进度就全露。
→ 用"行聚类 + 行内 cx 排序"生成全局顺序，每个图形只走一次。

**8. 字被画到一半断掉**
把一笔切成多段分别排序，墙/笔画被拦腰截断。
→ 排序单位是"整个封闭图形"，不许拆。

**9. 描完轮廓后内部有空洞**
只填外环，没处理内孔。
→ `rings` 里同时存外环和孔环，用 `evenodd` 一次填。

**10. 笔尖和显影边缘错开**
掩膜和笔尖位置用了两套进度算法。
→ 笔尖位置必须由同一条路径、同一个 `p` 求出；`penAt()` 与 `stampTo()` 共用 region 的 `t0/t1`。

**11. 倒拖进度条后画面花掉**
反向擦除掩膜会留下残影。
→ 倒拖时 `resetPen()` 全清，从 0 重放。用 rAF 合并 `oninput`，避免每次事件都重铺。

**12. 离屏画布只有左上角一小块有笔迹**
`maskCv` / `comp` 借主画布的尺寸变化做初始化条件，主画布已设成目标尺寸，它们永远停在 300×150。
→ 每块离屏画布各自判断自己的宽高。

## 页面 / 布局

**13. 底部按钮看不见**
grid 三行把 `.bar` 压扁/挤出视口。
→ `body{display:flex;height:100dvh}`，`aside{flex:0 0 196px}`，`.bar{flex:0 0 auto}`，`main/.stage{min-height:0}`。

**14. 换素材后还是旧图**
浏览器缓存了同名文件。
→ 换素材一律改文件名（`hand-20261103.png`），别指望刷新。

**15. 用户找不到导出的文件**
提示框用了 `text-overflow:ellipsis`，绝对路径被截断；内嵌预览面板还会静默拦截下载。
→ 去掉省略号、允许换行；录完 `POST /upload` 写盘，并复制到系统 Download。

## 字幕 / 配音

**16. 念的和写的不一样**
字幕取的是画面用的"改写摘要"，不是旁白原文。
→ 字幕与旁白同源，逐字一致；`check_project.py` 会做拼接比对。

**17. 字幕越到后面越偏，最多差 4.8 秒**
按字数比例分配时间 + 标点停顿模型。
→ 从音频取：能量包络找停顿，ASR 分段当锚点，块内 DP 对齐。

**18. 最后一句被拉到 16 秒**
只做"时长约束"的局部搜索，没有位置锚，边界整体漂移。
→ 代价里必须同时有位置项和语速项。

**19. 换音色后字幕全错位**
沿用了上一版音频的 ASR 锚点。
→ 换音频必须重跑 ASR → 锚点 → align → srt 全链路。

**20. TTS 把 IP 念成"一百九十二点一六八…"**
直接把 `192.168.3.158` 喂给 TTS。
→ 发音稿改写：`一九二点一六八点三点一五八`；字幕仍显示原文。

**21. 字幕劈词 / 标点单独成行**
按固定字数硬切。
→ 一行能放下就不拆；必须拆时在标点处对半开；加避头尾和孤行合并。

## 导出

**22. 播放器显示 0:00，进度条拖不动**
MediaRecorder 出的是 fragmented MP4，`mvhd.duration` 恒为 0。
→ 解析 `mdhd.timescale` + 最后一个 `tfdt`，把秒数写回 `mvhd.duration`；`serve.py` 已内置。

**附：不要在鸿蒙上折腾 ffmpeg**
`@ffmpeg-installer/linux-arm64` 解出来的二进制未签名 → 签名后直接 segfault（静态 glibc 版）。
→ 出片走浏览器 `captureStream` + `MediaRecorder`，老老实实按真实时间录。
