# 参数基线与调参

所有参数以 1024×1536 画布为基准，换画幅时按面积开方等比缩放：

```
k = sqrt(W * H / (1024 * 1536))
```

## trace_paths.js

| 参数 | 默认 | 作用 | 调大 | 调小 |
|---|---|---|---|---|
| `--th` | 0.4 | 墨迹二值化阈值（0..1，来自与纸色的色差） | 只留深墨，浅色块会消失 | 浅色块也当墨，纸纹会进来 |
| `--min` | 80·k | 小于此面积的连通域丢弃 | 去掉碎点，但小字会丢 | 保留小字，但噪点多 |
| `--hole` | 40·k | 小于此面积的孔洞填掉 | 少毛刺，但真孔会丢 | 保留细节，但轮廓锯齿多 |
| `--row-tol` | 76·k | 行聚类容差（像素） | 行更少，跨行跳笔更多 | 行更碎，顺序更"跳跃" |
| `--rdp` | 0.8·k | 轮廓抽稀容差 | 点更少、转角变钝 | 点更多、更贴边但文件大 |
| `--paper` | 四角平均 | 纸色（`r,g,b`） | — | 插画四角有装饰、取色不准时手动指定 |

**调参顺序**（只按这个顺序试，别一次改一堆）：

1. 先看 `paths/preview/<id>-path.png` —— 颜色是否覆盖所有内容、顺序是否从左到右。
2. 吻合率低 + 轮廓粘连 → 调 `--min`（增大）和 `--hole`（减小）。
3. 内容缺失 → 调 `--th`（减小）。
4. 轮廓毛刺多 → 调 `--rdp`（增大）和 `--hole`（增大）。
5. 纸色取错 → 显式 `--paper`。

## project.json

| 字段 | 建议值 | 说明 |
|---|---|---|
| `width` / `height` | 图片原尺寸 | 竖版 1024×1536，横版 1536×1024 |
| `captionHeight` | 竖版 220，横版 0 | 0 表示字幕叠在图上（需另调 `captionSize`） |
| `penWidth` | 11（1024 宽） | ≈ 画布宽的 1%，太细看不出"笔"，太粗糊住细节 |
| `captionSize` | 36（1024 宽） | ≈ 3.5% 画布宽 |
| `fit` | 0.96 | 四边各留 2% 纸边，永远不裁切 |
| `fps` | 25 | 再高会增加掉帧风险 |
| `exportScale` | 0.85 | 1024×1756 → 870×1492；想更清晰就 1.0，代价是体积 |
| `kbps` | 2600 | 讲解片够用；文字多可到 4000 |
| `drawSpeed` | 700 | 笔速 px/s；页面里据此算 `drawMs` |
| `minDrawMs` | 16000 | 单幕最短绘制时间，防止短幕"唰"一下画完 |
| `handTip` | [108, 62] | 笔尖在手素材里的像素坐标，换素材必须重校 |
| `handWidth` | 0.30 | 手宽占画布宽的比例 |
| `copyToDownload` | false | 导出后是否再复制一份到 Download；开着等于每支片双倍占用 |

`drawMs` 的实际公式（页面里）：

```
drawMs = min(幕长 × 0.95, max(minDrawMs, 路径总长 / drawSpeed × 1000))
```

留 5% 给幕尾的完整画面，不要画到最后一刻。
